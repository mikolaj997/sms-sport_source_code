# sms-sport_source_code - repozytorium nie zawiera kluczy api!
# Aplikacja sms-sport mająca zachęcić ludzi do uprawiania sportu dzięki stosowanemu kalkulatorowi oplacalności
## Część frontendowa napisana jest w reakcie i jego mniejszych bibliotekach(React Queries - do połączenia z node.js i React-Datepicker - do wyboru daty). Do wyświetlania mapki użyłem api mapboxa.
## Część beckendowa została napisana w Node.js. Potpięta baza danych to MongoDB.
